# بایگانی پاداش‌های تمام‌شده

پاداش‌هایی که بازه‌شان تمام شده، اینجا نگه داشته می‌شوند تا بعداً بشود
فرمول‌هایشان را دید یا مبلغ یک پاداش قبلی را دوباره بررسی کرد. **هیچ‌کدام
اجرا نمی‌شوند**: ردیفشان از `config/rewards.csv` برداشته شده و در
[rewards_archived.csv](rewards_archived.csv) نگه داشته شده (همراه تاریخ
بایگانی).

- منطق محاسبه‌ی هر پاداش در `builder.py` همان پوشه است و متن پیام در
  `render.py`.
- چند پاداش بایگانی‌شده همدیگر را با مسیر قدیمی `Rewards.{id}` import
  می‌کنند (مثلاً `padash-5040-mehr-report` از `padash-karshenasan-5040`)؛
  برای اجرای دوباره‌ی یکی از آن‌ها، پوشه‌اش را (و هر پوشه‌ای که import
  می‌کند) به `Rewards/` برگردان و ردیفش را به `config/rewards.csv`
  اضافه کن.
- تاریخچه‌ی پیام انبوه (`broadcasts.json`) این پاداش‌ها هنوز در صفحه‌ی
  `/broadcasts` پنل دیده می‌شود.
- فایل‌های داده (xlsx، roster، outputs و ...) مثل قبل gitignore هستند و
  فقط روی همین ماشین می‌مانند.
